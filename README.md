# Тесты на создание заказа клиентом и проверки, что по треку заказа можно получить данные о заказе
- Для запуска тестов должны быть установлены пакеты pytest и requests
- Запуск всех тестов выполняется командой pytest

Файл configuration.py - этот файл нужен для хранения конфигурации нашего запроса 
URL_SERVICE хранит базовый URL веб-сервиса, который используется для доступа к API
CREATE_ORDER хранит URL, который отпраялет запрос на создание заказа

Файл data.py — файл, в котором определяется тело запроса и заголовки

Файл sender_stand_request.py - в этом файле хранится функция, которая отправит наш POST запрос на создание заказа и GET запрос на получение данных о заказе по трек номеру. Не забыть импортировать в файл модули configuration, data и библиотеку requests.

Файл create_user_test - файл для написания автотеста по шагам
1. Выполнить запрос на создание заказа.
2. Сохранить номер трека заказа.
3. Выполнить запрос на получение заказа по треку заказа.
4. Проверить, что код ответа равен 200.

К проекту добавь файлы .gitignore и README.MD .
